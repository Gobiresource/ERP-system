# Гадны төслөөс сурсан зүйл

Хэрэглэгчийн явуулсан дизайны төсөл, сайт, зургаас сурсан санааг энд манай ERP-д тохируулан бичнэ. Шинэ дэлгэц зохиох, шалгахдаа уншина. SKILL.md-ийн дүрэмтэй зөрвөл SKILL.md давуу.

Кодыг хуулах эсэхийг эх сурвалжийн лицензээр шийднэ. Лицензгүй бол зөвхөн санааг нь авна.
