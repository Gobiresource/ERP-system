# Ant Design-ийн тохиргоо

2026-10-28-ны байдлаар Ant Design-ийн хамгийн сүүлийн хувилбар нь v6 (6.6.x). Доорх prop, token-ий нэрсийг суулгасан хувилбар дээр шалгана.

## ConfigProvider

- **`locale={mnMN}`, dayjs `mn`.** mn_MN орчуулгын алдааг засна:
  - эрэмбэлэх үйлдлийг "ангилах", "эрэмбэлэх" гэж хольсон байгаа тул нэгтгэнэ;
  - цонхны `okText` "Тийм" байгаа тул үйлдэл бүрт үйл үг өгнө;
  - хаах товчны шошго англиар "Close" байгаа тул "Хаах" болгоно.
- **`fontFamily`.** Ө, Ү үсэгтэй фонтоор солино. AntD-ийн анхдагч `-apple-system…` жагсаалт Windows дээр өөр фонт харуулдаг.
- **`theme.algorithm`.** Харанхуй горимд `darkAlgorithm` хэрэглэнэ. Горимыг `prefers-color-scheme`-ээр дагаж сонгоно (HIG).
- **`theme.token.motion`.** `prefers-reduced-motion` асаалттай бол `false` болгоно. AntD-д зөвхөн цөөн компонент энэ тохиргоог өөрөө дагадаг.

## Өнгө: тодролын засвар

AntD-ийн анхдагч өнгөнүүдийн тодролыг WCAG-ийн томьёогоор тооцоолсон. Бага гарсан нь:

| Token | Анхдагч | Тодрол | Яах |
|---|---|---|---|
| `colorPrimary` | `#1677ff` | Цагаан дээр 4.10:1 (цэнхэр товч дээрх цагаан текст ч мөн адил) | Илүү бараан өнгө, жишээ нь `#0958d9` (6.16:1), эсвэл брэндийн өнгийг шалгаж хэрэглэнэ |
| `colorError` | `#ff4d4f` | 3.27:1 | Текстэнд `#cf1322` (5.57:1) |
| `colorSuccess`, `colorWarning` | — | 2.27:1, 1.90:1 | Текстэнд бараан хувилбарыг хэрэглэнэ (`colorWarningText` гэх мэт) |
| `colorTextTertiary` (тайлбар, Form-ын тусламж) | — | 3.36:1 | `colorTextSecondary` (7.0:1) түвшинд хүргэнэ |
| `colorTextQuaternary` (placeholder) | — | 1.84:1 | 4.5:1 хүртэл бараан болгоно |
| `colorBorder` (талбарын хүрээ) | `#d9d9d9` | 1.41:1 | 3:1-ээс багагүй (`#8c8c8c`) эсвэл бүрхүүлтэй (filled) талбар |
| Focus-ийн хүрээ (`colorPrimaryBorder`) | `#91caff` | 1.74:1 | Бүх элементэд `:focus-visible` дээр 2 px, 3:1-ээс багагүй хүрээ (`#0958d9`, харанхуйд `#65a9f3`) |

Харанхуй горимын утгуудыг тусад нь шалгана. Эцсийн утгыг `theme.getDesignToken()`-оор гаргаж тооцоолно.

## Хэмжээ ба зай

- **Үсэг.** `fontSize: 14`, `fontSizeSM: 12`. Утсанд (`≤ 640px`) үндсэн текст болон оролтын талбар 16 px.
- **Удирдлагын өндөр.** Анхдагч `controlHeight` 32 px. Эхлэлийн санал нь 36 px (`controlHeightSM` 28, `controlHeightLG` 44). Дизайн систем дээр эцэслэнэ.
  - Утсанд гол үйлдэлд `size="large"` хэрэглэнэ.
  - Компакт алгоритм (28 px, 12 px текст) утсанд тохиромжгүй.
- **Зай.** `paddingMD`, `marginMD` 20 px нь шатлалаас гадуур тул 24 болгоно. Хуудасны формд `Form` `itemMarginBottom` 24–32 px.
- **Сүлжээ.** AntD 24 баганатай, `Row gutter={[16, 16]}`-ээс эхэлнэ.

## Компонентууд

| Хэрэгцээ | AntD | Тэмдэглэл |
|---|---|---|
| Бүтэц | `Layout`, `Sider` (240–256), `Menu` | Толгой 48–56 px. ХХК солих нь толгой дахь `Dropdown`. Хуудасны толгой (гарчиг, буцах, үйлдэл) бэлэн компонентгүй тул өөрсдөө хийнэ |
| Хүснэгт | `Table` | `tables.md` |
| Форм | `Form` | `forms.md` |
| Богино мэдэгдэл | `notification` | `role: 'status'`, `duration: 5`. `message` нь үргэлж `role="alert"` тул хэрэглэхгүй |
| Баннер | `Alert` | `showIcon`, шаардлагатай бол `action` |
| Цонх | `Modal`, `modal.confirm` | `okText`-д үйл үг, `okButtonProps={{ danger: true }}`, формтой бол `maskClosable={false}` |
| Хажуугийн самбар | `Drawer` | 5-аас олон талбартай форм, дэлгэрэнгүй харах |
| Төлөв | `Tag` + дүрс | `Badge status` цэгийг ганцаар нь хэрэглэхгүй |
| Хоосон төлөв | `Empty`, `Result` | Өөрсдийн текст, нэг товч |
| Ачаалж буй төлөв | `Skeleton`, `Button loading` | Хүснэгтэд спиннер биш, араг |
| Дүрс | `@ant-design/icons` (MIT) | Apple SF Symbols, SF Pro фонтыг вэб апп-д хэрэглэх эрхгүй |
| Дүрстэй товч | `Button` + `Tooltip` | `aria-label` заавал |
