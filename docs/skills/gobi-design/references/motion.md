# Хөдөлгөөн

Хөдөлгөөний утгыг Pane-ийн кодоос (GSAP-ийн утга, CSS transition) уншиж авч, Говь ERP-д хэрэглэж шалгасан. GSAP байхгүй төсөлд ижил хугацаа, муруйг CSS transition эсвэл Web Animations-аар хийнэ (`back.out` ≈ `--spring`, `power3.out` ≈ `--ease`). Ихэнх нь үсрэлттэй муруйтай. Хөдөлгөөн нь юу болсныг ойлгоход тусална, чимэглэл биш.

## Хугацаа ба муруй

- Хурдан (hover, дарах, focus): 100–200 ms. Товч, мөрийн дэвсгэр 0.2s-д солигдоно.
- Үндсэн (нээх, хаах, жижиг оролт): 200–300 ms. Мэдээллийн дэлгэцэд 300 ms-ээс урт хөдөлгөөн байхгүй. Гарах нь орохоос хурдан.
- Муруй:
  - `--ease`: `cubic-bezier(.22, .8, .24, 1)`, ерөнхий;
  - `--spring`: `cubic-bezier(.34, 1.45, .55, 1)`, toggle, checkbox, 0.35–0.38s.
- Hover дээр нэг л шинж өөрчлөгдөнө: дэвсгэр эсвэл хүрээ. Мөр, жагсаалт зөвхөн дэвсгэрээ өөрчилнө.
- Зөвхөн `transform`, `opacity`-г хөдөлгөнө. `height`, `width`, `top`, `letter-spacing`, `blur`, `backdrop-filter`-ийг хөдөлгөхгүй. Өндрийг `grid-template-rows: 0fr → 1fr`-ээр өөрчилнө.
- Анхдагч төлөв нь `opacity: 0` эсвэл шилжсэн байрлалтай элемент байхгүй. JS ачаалагдаагүй ч дэлгэц бүрэн байна.

## Pane-ийн хөдөлгөөнүүд

- **Хуудас нээгдэх.**
  - Гарчгийн үсэг бүр доороос эргэлдэн гарна: `yPercent 115→0`, `rotation 6°→0`, 0.85s `power4.out`, үсэг бүр 0.022s зөрүүтэй.
  - Карт, мөр: `opacity 0→1`, `y 8px→0`, 0.55s `power3.out`, 0.035s зөрүүтэй.
- **Цэс солих.** Идэвхтэй цэсний ард «линз» гулсана: 0.5s `power3.inOut`. Сегментийн линз (`.seg__pill`) мөн ингэж гулсана.
- **Карт чирэх (самбар, жагсаалт, хуудас).**
  - **Өргөх.** Карт өргөгдөнө: `scale 1.045`, `back.out(2.4)`. Бага зэрэг хазайж, `shadow-lift` сүүдэртэй хөвнө.
  - **Хуучин байр.** Хуучин байранд нь тасархай хүрээтэй хоосон зай үлдэнэ.
  - **Бусад карт.** Бусад карт зай тавьж шилжинэ: 0.55s `power3.inOut`.
  - **Тавих.** Карт жийрэглэнэ: `scaleX 1.03`, `scaleY .96` → 1, 0.65s `elastic.out(1, 0.45)`.
  - **Дараа нь.** Арал дээр «… руу зөөлөө» ба «Буцаах» гарна.
  - **Хаана хэрэглэх.** Ажлын самбар, PDF-ийн хуудас гэх мэт чирдэг бүх зүйлд адилхан хөдөлгөөн хэрэглэнэ.
- **Дуусгах (ажил, мөр тэмдэглэх).**
  - Тэмдэглэгээ эргэлдэн томорно: `scale 0`, `-40°` → 1, 0.75s `back.out(3.4)`.
  - Долгион тойрог тархана: `scale .5 → 2.8`, 0.8s.
- **Арал.**
  - Тэлэхдээ 0.5s `power3.inOut`, хумигдахдаа 0.35s `power3.in`.
  - Мэдэгдлийн текст 0.3s-д гарч, 0.3s-д алга болно.
- **Цонх.** Арын `scrim` 0.28s-д бүдгэрч гарна. Цонх жижгээс томорно (`back.out`). Арын бүрхүүлд blur хэрэглэхгүй.
- **Календарь.**
  - Тов гарч ирэх: `scale .8 → 1`, 0.5s `back.out(2.2)`.
  - Сар, долоо хоног солих: 56px гулсалт, 0.6s `expo.out`.
- **Шүүлтүүр солих.** Картууд байраа сольж гулсана (FLIP): 0.65s `power3.inOut`.
- **Шилэн хавтас.** Заахад хавтас 6px, цааснууд 8, 16, 24px дээшилнэ, 0.5s `--ease`. «Хөдөлгөөн багасгах» үед хазайхгүй.

## Хөдөлгөөн багасгах

- Хөдөлгөөнийг бүрэн арилгахгүй, бага, зөөлөн болгоно. Байрлал, хэмжээний хөдөлгөөнийг 200 ms-ээс богино тунгалаг шилжилтээр солино.
- Өнгө, ачааллын тэмдэг, утга бүхий хариу үйлдэл хэвээр үлдэнэ.
- Хөдөлгөөнт класс бүр өөрийн дүрэмтэй байж, эцсийн төлвөө бичнэ.
- Давталт: зөвхөн ачааллын тэмдэг (`.spin`) давтагдана. Таб нуугдсан үед зогсоно.

## Дахин хэрэглэх загварууд

- **Тоо шинэчлэгдэх.** Зөвхөн солигдсон цифр эргэлдэнэ (150–200 ms). Анх ачаалахад тоолох нь нэг л удаа, 300 ms-ээс богино.
- **Араг (skeleton) → агуулга.** 150–200 ms тунгалаг шилжилт, хэмжээ өөрчлөгдөхгүй.
- **Спиннер.** 150–300 ms-ийн дараа л гарна. Гарсан бол 300 ms-ээс багагүй байна. 2 s-ээс удаан бол текст нэмнэ.
- **Шошго солих.** «Хадгалах → Хадгалж байна… → Хадгалсан» бүх төлвийг нэг grid нүдэнд давхарлана. Ингэвэл өргөн өөрчлөгдөхгүй.
