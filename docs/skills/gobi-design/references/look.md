# Харагдах байдал

Бүх утга `assets/tokens.css`-д `--нэр` хэлбэрээр байна. Энд тус бүрийг хаана хэрэглэхийг бичив. Хоёр горимтой: `[data-theme="light"]` ба `[data-theme="dark"]`.

## Агуулга
1. Ханын зураг ба шил
2. Өнгө
3. Үсэг
4. Зай, булан, сүүдэр, хэмжээ
5. Байршил
6. Харанхуй горим, хүртээмж

## 1. Ханын зураг ба шил

- **Ханын зураг.** Хуудасны ард ханын зураг байна. Хавтгай: `wall-ash`, `wall-sand`, `wall-sage`. Долгионтой: `wall-aurora`, `wall-smoke`, `wall-tide`, `wall-bloom`, `wall-ember`, `wall-grove`, `wall-dusk` (эдгээрийн суурь өнгө).
- **Ханын зургийн градиент.** Долгионтой ханын зурагт зөөлөн радиал градиент нэмнэ. Жишээ нь `assets/components.css` дахь `.ds-stage`:
  - `blue`, `purple` 22–26%;
  - суурь нь `wall-aurora`.
- **`.glass` шилэн гадаргуу.** Давхаргууд:
  ```css
  background:
    radial-gradient(260px circle at var(--gx, -400px) var(--gy, -400px), var(--glint), transparent 70%),
    linear-gradient(172deg, var(--sheen) 0%, transparent 34%),
    var(--glass);
  backdrop-filter: blur(12px) saturate(190%) brightness(1.06);   /* харанхуйд blur 14px, 175%, .95 */
  box-shadow: var(--depth), var(--shadow);
  border-radius: var(--r-lg);
  ```
  - **Хүрээ.** `::before` дээр conic гэрэлтсэн хүрээ: `rim-hi` → `rim-lo` → `rim-mid`. Mask-аар зөвхөн 1.25px хүрээ үлдээнэ.
  - **Гэрлийн толбо.** `--gx`, `--gy`-г `assets/glint.js` заагчийн байрлалаар тавина. Зөвхөн жинхэнэ заагчтай төхөөрөмж дээр ажиллана.
- **Гурван түвшин.**
  - `glass`: карт, хажуугийн цэс, тоон хавтан.
  - `glass-chrome` (`.glass--chrome`): хуудас доогуур нь гүйдэг дээд мөр.
  - `glass-thick` (`.glass--thick`, blur 28px, харанхуйд 30px): цонх, унждаг цэс, утасны доод цэс.
- **Хурд.** Хавтгай ханын зураг дээрх картууд blur хийхгүй, учир нь хавтгай өнгийг бүдгэрүүлэхэд ижил өнгө гардаг. Энэ нь гүйлгэлт, хуудас солих хурдыг ихээхэн сайжруулдаг.
  - Хавтгай ханын зурагтай бол `<html data-wall="flat">` гэж тэмдэглэнэ.
  - Гэрлийн горимд картууд арай цагаан (0.6) болно. Хажуугийн цэс, дээд мөр, цонх blur-аа хадгална, учир нь хуудас тэдний доогуур гүйдэг.
- **Тунгалаг байдлыг багасгах** үед бүх шил `glass-solid`, blur-гүй болно.
  - Системийн тохиргоо (`prefers-reduced-transparency`) автоматаар ажиллана.
  - Апп-ын тохиргооноос асаах бол `<html class="is-solid">`.
- **Хязгаар.**
  - Шилийг шилэн дотор хоёр түвшнээс илүү давхарлахгүй.
  - `backdrop-filter`-ийг хөдөлгөхгүй.
  - Шилэн дээрх текстийн тодролыг ханын зураг бүр дээр, хоёр горимд хэмжинэ. `text-2` нь 0.70 тунгалаг тул доорх өнгөнөөс хамаарна.

## 2. Өнгө

- **Харьцаа 60-30-10.**
  - 60%: ханын зураг ба шил.
  - 30%: `fill`, `glass-solid` зэрэг хоёрдогч гадаргуу.
  - 10%-иас бага: `accent`.
- **Текст.**
  - `text`: үндсэн.
  - `text-2`: дэд гарчиг, шошго.
  - `text-3`: зөвлөмж, placeholder.
- **Голлох өнгө.**
  - `accent`: товч, сонголт, switch. Дээрх текст цагаан, товч нь 94→78% бараан градиенттай.
  - `accent-ink`: голлох өнгөтэй текст, холбоос, focus хүрээ.
  - `accent-soft` (14%): тодруулга, «ghost» товчны hover, холбогдсон мөр.
  - Хэрэглэгч тохиргооноос сольж болно: `accent-purple`, `accent-pink`, `accent-orange`, `accent-green`, `accent-graphite`. Тус бүр `…-ink`-тэй.
- **Нэг дэлгэцэд** голлох өнгө 4-өөс бага удаа гарна. Дүрс, гарчиг, тоон утгад хэрэглэхгүй.
- **Hue өнгө.** `blue`, `purple`, `pink`, `orange`, `green`, `teal`, `indigo`, `yellow`.
  - Төсөл, хүн, ангилал, графикийн цувааг ялгана.
  - `.hue--<нэр>` класс `--hue`-г тохируулна.
  - Хүний өнгийг нэрээс hash-аар тогтвортой сонгоно.
  - Шар, улбар шар дэвсгэр дээр бараан текст.
- **Төлөв.** Үргэлж дүрс эсвэл үгтэй хамт:
  - сайн: `ok-ink`;
  - муу: `bad-ink`;
  - аюул: `danger`;
  - ач холбогдол: `prio-urgent`, `prio-high`, `prio-medium` (дэвсгэр нь тухайн өнгөний 14–16%).
- **Дүүргэлт.**
  - `fill`: оролтын талбар, сегмент, шошго.
  - `fill-hover`: мөрийн hover.
  - `sep`: 1px хуваах зураас.
  - `scrim`: цонхны ард, blur-гүй.
- **Тусгай гадаргуу.**
  - `paper…`: баримтын цаас.
  - `ins-…`, `del-…`: хувилбарын харьцуулалт.
  - `island…`: хар арал.
  - `board-…`: самбар.
  - `folder-<hue>-from|to`: шилэн хавтас.

## 3. Үсэг

- **Фонт.** Golos Text (OFL, Google Fonts). Ө, Ү нь `cyrillic-ext`-д байдаг.
- **Жин.**
  - 400: текст.
  - 500–560: мөрийн нэр, шошго.
  - 600: товч.
  - 650: карт, цонхны гарчиг.
  - 700: хуудасны гарчиг, тоо.
  - 300-аас нимгэн жин хэрэглэхгүй.

| Хэв маяг | Хэмжээ / мөр / жин | Хаана |
|---|---|---|
| Хуудасны гарчиг | 34–58px (`clamp(34px, 2.2vw + 14px, 58px)`) / 1.02 / 700, `-0.03em`, `text-wrap: balance` | Хуудасны толгой |
| Хавтасны нэр | 16–24px / 1.15 / 700 | Шилэн хавтас (цагаан) |
| Тоо | 23px / 1.1 / 700, `-0.02em`, `tabular-nums` | Тоон хавтан |
| Цонхны гарчиг | 18px / 1.25 / 650 | Цонх |
| Картын гарчиг | 17px / 1.25 / 650 | Карт |
| Цэсний гарчиг | 16px / 1.2 / 650 | Унждаг цэс |
| Үндсэн текст | 15px / 1.45 / 400 | Бүх текст |
| Нягт текст | 14px / 1.45 / 400 | Хоосон төлөв, мэдэгдэл |
| Мөрийн нэр | 14.5px / 1.3 / 560 | Жагсаалт, цэс |
| Шошго | 13px / 1.3 / 600 | Талбарын нэр |
| Тайлбар | 12.5px / 1.35 / 560 | Тоон хавтангийн шошго |
| Тэмдэг | 12px / 1 / 650 | Шошго, ач холбогдол |
| Товч | 15px (жижиг нь 14px) / 600 | Товч, сегмент |

- **Хязгаар.**
  - Нэг дэлгэцэд 5-аас олон фонтын хэмжээ хэрэглэхгүй.
  - Товч, цэс, табын текст хоёр мөр болохгүй.
  - Утсанд оролтын талбар 16px-ээс багагүй (iOS томруулахгүй).

## 4. Зай, булан, сүүдэр, хэмжээ

- **Зай.** `space-1` 4, `space-2` 8, `space-3` 12, `space-4` 16, `space-6` 24, `space-8` 32, `space-12` 48, `space-16` 64. Үүнээс гадуурх утга хэрэглэхгүй.
  - Хүрээтэй хайрцгийн дотор 12–16px.
  - Утасны ирмэгээс 16px-ээс багагүй.
  - Гарчгийн дээрх зай доорхоос их.
- **Булан.**
  - `r-pill` (999px): товч, сегмент, шошго.
  - `r-sm` 12: жижиг.
  - `r-tile` 16: хавтан, тэмдэглэл, цэсний мөр.
  - `r-md` 18: тоон хавтан.
  - `r-lg` 24: шил, цэс.
  - `r-xl` 30: карт.
  - `r-modal` 32: цонх.
  - `r-paper` 10: цаасан карт.
- **Сүүдэр.**
  - `shadow`: карт, цэс.
  - `shadow-lift`: өргөгдсөн, чирж буй зүйл.
  - `depth`: шилний дотоод гүн.
  - `lens-glow`: сегментийн линз.
  - `board-lie`, `board-lift`: самбар дээрх цаас.
  - `island-shadow`: арал.
- **Хэмжээ.**
  - `btn-h` 42 (жижиг нь 34).
  - `ibtn` 40.
  - `seg-h` 34.
  - Хүрэлттэй дэлгэцэд 44 (`touch`).
  - Дүрс 20px, зураас 1.8. Товчинд 18px, зураас 2.1. Дүрсийн сан нь lucide.
  - Focus хүрээ 2.5px `accent-ink`, 2px зайтай.

## 5. Байршил

- **Компьютер.**
  - Хажуугийн цэс `side-w` (252px), шилэн.
  - Хуудасны хамгийн их өргөн `frame` (1840px).
  - Дээд мөр нь шилэн, голдоо хар арал.
- **Утас.** Доод хөвөгч цэс (4–5 хэсэг, «Бусад»), хайлтын дугуй товч.
- **Хуудасны толгой** (`.head`):
  - том гарчиг, дэд гарчиг;
  - 4-өөс ихгүй тоон хавтан;
  - гол үйлдэл баруун талд. Багтахгүй бол үйлдлүүд шинэ мөрөнд шилжинэ.
- **Самбар.** Хэрэглэгчийн гол ажлаар (хүлээгдэж буй зүйл) эхэлнэ. «Мэндчилгээ ба 4 карт» хэрэглэхгүй.
- **Форм.** Нэг баганатай, `form-max` (720px)-аас өргөн биш.
  - Эхлээд тухайн газар нь засна.
  - Урт формыг хажуугийн самбарт (`.drawer`) хийнэ.
  - Цонхыг (`.modal`) зөвхөн ажлыг тасалдуулах шаардлагатай үед хэрэглэнэ.
- **Хүснэгт.**
  - Тоо баруун тийш тэгшилж `tabular-nums`-тай. Мөр 40–48px.
  - Утсанд мөрийн нэр ба үйлдэл харагдана, эсвэл карт мөр болгоно.
- **z-index шат.**
  - энгийн 1, өргөгдсөн 10;
  - унждаг цэс 100, наалттай 200;
  - навигаци 300, цонх 400;
  - мэдэгдэл 500, tooltip 600.

## 6. Харанхуй горим, хүртээмж

- **Харанхуй горим.**
  - `[data-theme="dark"]`-ийн утгуудыг хэрэглэнэ. Гэрлийн горимыг урвуулж болохгүй, тусад нь зохионо.
  - Өргөгдсөн гадаргуу хуудаснаас цайвар байна.
  - Голлох өнгө арай цайвар, бага ханалттай.
  - Харанхуйд шилэн дээрх цагаан текст `#fff` биш (`text`: `#f5f5f7`).
- **Тодрол** (WCAG 2.2 AA):
  - текст 4.5:1;
  - том текст (24px, эсвэл 19px тод), хүрээ, дүрс, focus 3:1.
  - Хоёр горимд, ханын зураг бүр дээр шалгана.
- **Хүрэлттэй дэлгэц.** Дарах талбай 44px-ээс багагүй.
- **Хэмжээ.** 200% томруулахад юу ч тасрахгүй, 320px өргөнд ажиллана.
- **1px зураас.** Хүснэгт, торны 1px зураасыг хүрээгээр (border) зурна, давтагддаг градиентаар зурахгүй. Градиент 125%, 150% томруулсан дэлгэцэд зарим зураасыг бүдүүн, бүдэг болгодог.
