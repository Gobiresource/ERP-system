# Шалгах

Дэлгэцийг «дууслаа» гэхээс өмнө эдгээрийг шалгана. Зургийг заавал өөрөө нээж харна. Скрипт өнгө, давхцлыг хэлэхгүй.

## Зураг авах (`scripts/shoot.js`)

```bash
node scripts/shoot.js <хаяг эсвэл файл> <хавтас> [--scale]
```

- **Авах зургууд.**
  - Компьютер 1440×900 ба утас 390×844 (iPhone шиг, 3× нягт, хүрэлттэй).
  - Тус бүр гэрэл ба харанхуй горимд.
  - Нэмж «хөдөлгөөн багасгах» горимд нэг зураг.
- **`--scale`.** Мөн 125% ба 150% жинхэнэ томруулалттай дэлгэцийн зураг авна. Нимгэн зураас, тортой дэлгэцэд заавал хэрэглэнэ.
  - Playwright-ийн `deviceScaleFactor` жинхэнэ томруулсан дэлгэцээс өөрөөр зурдаг.
  - Тиймээс скрипт Chromium-ийг `--force-device-scale-factor`-оор нээдэг.
- **Мэдээлэх зүйл.** Хуудасны алдаа, хажуу тийш гүйлгэгдэх байдал (overflow) байвал хэвлэнэ.
- **Шаардлага.** Playwright ба Chromium хэрэгтэй. Аль хэдийн суусан бол дахин суулгахгүй.
- **Горим солих.** Скрипт гэрэл, харанхуйг системийн горимоор (`colorScheme`) сольдог. Шинэ хөтчийн цонхонд хадгалсан сонголт байхгүй тул `theme.js` системийн горимыг уншина. Хуудас горимоо өөр аргаар сонгодог бол скриптэд тэр алхмыг нэмнэ.

## Жагсаалт

### Харагдах байдал
- [ ] Компьютер, утас, гэрэл, харанхуй дөрвөн зургийг бүгдийг нь харсан.
- [ ] Хажуу тийш гүйлгэгдэхгүй. 320px өргөнд ажиллана. 200% томруулахад юу ч тасрахгүй.
- [ ] Товч, цэс, табын текст хоёр мөр болохгүй. Жинхэнэ монгол урт текстээр 320, 390, 1440px-д шалгасан.
- [ ] Бүх зай, булан, хэмжээ token-оос авсан.
- [ ] Нэг дэлгэцэд 5-аас олон фонтын хэмжээ алга.
- [ ] Голлох өнгө 4-өөс бага удаа гарсан.
- [ ] Хүрээтэй хайрцаг дотор 12–16px зай. Утсанд ирмэгээс 16px-ээс багагүй. Гарчгийн дээрх зай доорхоос их.
- [ ] Тор, хүснэгтийн 1px зураас 125%, 150%-д бүгд ижил нарийн (`--scale`).

### Тодрол ба өнгө
- [ ] Текст 4.5:1, том текст, хүрээ, дүрс, focus 3:1. Хоёр горимд хэмжсэн.
- [ ] Хагас тунгалаг текстийн (`text-2`, `text-3`) тодролыг шил орно, гадаргуу бүр дээр хэмжсэн.
- [ ] Зөвхөн өнгөөр ялгасан зүйл алга. Төлөв бүр дүрс эсвэл үгтэй.
- [ ] Харанхуй горимд `#000`, `#fff` алга (хар арлаас бусад). Дахин ачаалахад горим анивчихгүй.
- [ ] Текст сонголт, курсор, scrollbar, `color-scheme` хоёр горимд таарна.

### Хөдөлгөөн ба тунгалаг байдал
- [ ] «Хөдөлгөөн багасгах» асаалттай үед дэлгэц бүрэн. Тунгалаг ба өнгөний хариу үйлдэл үлдсэн.
- [ ] «Тунгалаг байдлыг багасгах» үед шил хатуу (`glass-solid`), текст уншигдана.
- [ ] Зөвхөн `transform`, `opacity` хөдөлнө. JS ачаалагдаагүй ч дэлгэц бүрэн.
- [ ] Алдаа, ачааллын тэмдэг, тоо гарахад хажуугийн юу ч хөдлөхгүй.

### Гар ба хүрэлт
- [ ] Бүх үйлдэл гараар (Tab, Enter, Esc) хийгддэг. Focus тод харагдана, наалттай хэсгийн доор нуугдахгүй.
- [ ] Хүрэлттэй дэлгэцэд дарах талбай 44px-ээс багагүй. Зөвхөн hover-оор гардаг зүйл алга.
- [ ] Дүрстэй товч бүр `aria-label`-тэй. Хуудас солигдоход focus үндсэн агуулга руу шилжинэ.

### Төлөв ба текст
- [ ] Хоосон, ачаалж буй, алдаа, эрхгүй төлөв бүгд бий.
- [ ] Товч бүр үйл үгтэй. «OK», «Тийм» гэсэн товч алга.
- [ ] Алдааны текст: юу болсон + яагаад + яаж засах. Алдаа өөрөө алга болохгүй.
- [ ] Сервер хариулахаас өмнө амжилтын мэдэгдэл гарахгүй.

### Хүнд өгөгдөл
- [ ] 100+ тэмдэгттэй нэр, 1000+ мөр, хоосон утга, маш том тоо.
- [ ] Илгээх товчийг 10 удаа дарах. Форм дунд хуудсыг дахин ачаалах.
- [ ] Сервер 401, 403, 404, 429, 500 буцаах.

## Хувийн мэдээлэл

- **Жинхэнэ өгөгдөлтэй зураг.** Жинхэнэ ажилтан, үйлчлүүлэгчийн мэдээлэл харагдаж байвал нэрийг нь дарж (blur эсвэл хайрцаг) зураг авна. Шалгасны дараа зургийг устгана.
- **Тестийн өмнө.** Жинхэнэ түлхүүртэй серверийг зогсооно. Тэгвэл тест жишээ өгөгдлийг харна.
- **Чатад.** Нэр, регистрийн дугаар, хувийн мэдээллийг чатад хэвлэхгүй. Зөвхөн тоо, дүн, талбарын нэрийг харна.
