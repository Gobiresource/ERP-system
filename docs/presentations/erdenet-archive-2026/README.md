# Илтгэл: архивын баримтыг хиймэл оюун ухаанаар ялгаж, ангилан цэгцлэх

«Архивын баримтыг судалгааны эргэлтэд оруулах нь» эрдэм шинжилгээний бага хуралд зориулсан илтгэл (2026 оны 11 дүгээр сар, Эрдэнэт хот). Хэрэглэгчийн 11 хуудас өгүүллээс (PDF) 2026-11-11-нд хийсэн.

## Файлууд

| Файл | Юунд хэрэглэх |
|---|---|
| `Erdenet-arhiv-AI-iltgel-2026.pptx` | Үндсэн илтгэл. PowerPoint-д нээж, засаж, үзүүлнэ. 21 слайд, 16:9. |
| `Erdenet-arhiv-AI-iltgel-2026.pdf` | Нөөц хувилбар. Аль ч компьютерт яг ижил харагдана. |
| `fonts/` | Golos Text фонтын хоёр жин (Regular, Bold) ба лиценз. PowerPoint фонтыг харуулахгүй бол суулгана. |
| `src/` | Илтгэлийг угсардаг код, зураг. Claude дараа засахад хэрэглэнэ. |

## Илтгэлийн бүтэц

1. Нүүр
2. Хагас зуун жилийн баримтын сан (түүх, 35 тонн)
3. Асуудал: хадгалалт өндөр түвшинд, хайлт гар аргаар
4. 1-р шалтгаан: сканнердсан зураг бол өгөгдөл биш
5. 2-р шалтгаан: орос, монгол хэлний саад
6. 3-р шалтгаан: нэг баримт олон сэдэвт хамаарна
7. 4-р шалтгаан: ачаалал ба эх баримтын элэгдэл
8. Харьцуулсан хүснэгт
9. Дөрвөн шат (тойм)
10. 1, 2-р шат
11. 3, 4-р шат
12. Өгөгдлийн бүтэц (JSON-ы 8 бүлэг)
13. Жишээ: нэг баримтыг хэрхэн таньдаг вэ
14. Жишээ: уншсаны дараа юу гардаг вэ
15. Судлаачдад нээгдэх боломж
16. Шууд үр өгөөж
17. Аюулгүй байдлын хосолмол горим
18. Замын зураглал ба туршилтаар хэмжих үзүүлэлт
19. Дүгнэлт
20. Ашигласан эх сурвалж
21. Төгсгөл, асуулт хариулт

Слайд бүрийн доор илтгэгчийн тэмдэглэл бий: өгүүллийн тухайн хэсгийн бүтэн бичвэр.

## Жишээ баримтын тухай (13, 14-р слайд)

- **Хуудас нь зохиомол.** Орос хэлээр бичгийн машинаар бичсэн тушаалын дүр төрхтэй жишээ хуудас (`src/specimen.html`). Архивын бодит баримт биш. Зураг дээрээ «ОБРАЗЕЦ» гэсэн улаан дардастай, слайд дээр ч тайлбартай.
- **Уншилт нь бодит.** Хуудсын зургийг хиймэл оюун ухааны харааны загварт өгүүллийн JSON бүтцээр уншуулсан. Гаралт нь `src/assets/reading.json`-д яг хэвээрээ бий.
  - Загвар зөвхөн зургийг харсан, хуудсын эх бичвэрийг хараагүй.
  - Зураг дээрх хүрээнүүд нь загварын өөрийнх нь заасан байрлал (`regions`).
  - Бүдгэрсэн «25 мая» гэсэн огноог загвар таамаглаж нөхөөгүй, `[?]` гэж тэмдэглэсэн.
  - Слайд дээрх зураг ба уншуулсан зураг нэг ижил болохыг цэг бүрээр нь тулгаж шалгасан.
- **Туршилтын үр дүн биш.** Өгүүллийн 4.2-т байгаа хэмжүүрийг (нарийвчлал, алдааны хувь) туршилтын дараа бөглөнө. Илтгэлд тоо зохиож оруулаагүй.
- **Жинхэнэ скан ирвэл.** Зургийг сольж, шинээр уншуулаад `reading.json`-ийг солино. 14-р слайд түүнээс өөрөө бөглөгдөнө. 13-р слайдын баруун талын товч тайлбарыг `build.js` дахь `SAID`-д гараар бичнэ.

## Фонт

- Илтгэл бүхэлдээ Golos Text (OFL лицензтэй, үнэгүй). Монгол Ө, Ү үсэгтэй. Төгрөгийн тэмдэг (₮) энэ фонтод байхгүй тул илтгэлд хэрэглээгүй.
- Хоёр жинг `.pptx` файл дотор нь суулгасан (`src/post.py`). Ингэснээр фонт суугаагүй компьютерт ч PowerPoint зөв харуулах ёстой.
- **Шалгасан:** суулгасан фонтын файл бүтцийн хувьд зөв, доторх фонт нь эх файлтайгаа яг ижил.
- **Шалгаагүй:** жинхэнэ PowerPoint дээр нээж үзээгүй. Энэ орчинд PowerPoint байхгүй, LibreOffice 24.2 нь суулгасан фонтыг уншдаггүй.
- Илтгэх компьютер дээр урьдчилан нээж шалгана. Фонт өөр харагдвал:
  1. дээд талд гарах «Enable Editing» товчийг дарна;
  2. болохгүй бол `fonts/` доторх хоёр `.ttf` файлыг суулгана (файл дээр хоёр дарж «Install»);
  3. эсвэл PDF хувилбараар үзүүлнэ.

## Харагдах байдал

Говь ERP-ийн дизайн системийн (Pane) харагдацыг PowerPoint-д буулгасан:
- зөөлөн ханын зураг дээрх шилэн карт;
- дээд зүүн буланд хар «арал» (хэсгийн дугаар, нэр, явцын цэг);
- хэрэглэгчийн шилэн хавтас;
- lucide дүрс, нэг голлох өнгө.

Голлох өнгө нь зэс (`accent-orange`), ханын зургийн гэрэл нь зэс ба оюу. Эрдэнэтийн зэсийн хүдэрт тааруулсан.

## Засах

Жижиг засварыг PowerPoint дотор шууд хийж болно: бүх бичвэр, хэлбэр засагдана.

Claude-аар засах бол `src/build.js`-д слайд бүр тусдаа хэсэгтэй. Дахин угсрах:

```bash
cd docs/presentations/erdenet-archive-2026/src
npm install                 # pptxgenjs (слайд угсардаг сан)
pip install fonttools       # post.py-д хэрэгтэй
npm run build               # ../Erdenet-arhiv-AI-iltgel-2026.pptx гарна
```

- `build.js` бичвэр бүрийг фонтын өргөнөөр хэмжиж, хайрцагтаа багтахгүй бол `check:` гэж анхааруулна.
- Слайд дээрх бичвэр бүр том үсгээр эхэлнэ: жагсаалтын мөр, шошго, тайлбар (хэрэглэгчийн хүсэлт, 2026-11-12). Жижиг үсгээр эхэлбэл `build.js` мөн анхааруулна. JSON-ы түлхүүр, холбоос үл хамаарна (`code: true`).
- Дараа нь LibreOffice-оор PDF болгож, зураг бүрийг харж шалгана.
- PDF-ийг шинэчлэх: `soffice --headless --convert-to pdf --outdir .. ../Erdenet-arhiv-AI-iltgel-2026.pptx`. Энэ үед Golos Text компьютерт суусан байх ёстой (`fonts/`-оос `~/.fonts`-д хуулна).

| Файл | Үүрэг |
|---|---|
| `build.js` | 21 слайдын агуулга, байрлал |
| `lib.js` | өнгө, гурван хүрээ (нүүр, агуулга, харанхуй), шилэн карт, арал, шошго зэрэг туслах хэсэг |
| `post.py` | өнгөний загварыг PowerPoint-ийн theme-д бичиж, фонтыг файл дотор суулгана |
| `make-assets.js` | ханын зураг, шилэн хавтас, дүрсийг зурна (Playwright, sharp, lucide-static хэрэгтэй) |
| `shoot-specimen.js`, `specimen.html` | жишээ хуудсыг зурна |
| `read-specimen.js` | жишээ хуудсыг OpenRouter-оор уншуулна (түлхүүр ажиллаж байвал) |
| `make-notes.py` | өгүүллийн бичвэрээс (`assets/paper.txt`) илтгэгчийн тэмдэглэл гаргана |
| `make-widths.py` | фонтын үсгийн өргөнийг гаргана |
