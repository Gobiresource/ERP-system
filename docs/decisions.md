# Шийдвэрийн бүртгэл

ERP системийн талаар хэрэглэгчтэй тохиролцсон шийдвэрүүд. Шинэ шийдвэрийг огноотойгоор нэмнэ.
Шинэ session эхлэхдээ эндээс уншиж, үргэлжлүүлнэ.

## 2026-10-28

### Ажиллах зарчим

- Компанид техникийн мэдлэгтэй хүн байхгүй. Кодыг бичих, байршуулах, баримтжуулах ажлыг бүхэлд нь Claude хийнэ.
- Тиймээс бүх зүйл автомат байна: GitHub-д push хийхэд автоматаар байршина, өдөр бүр backup хийнэ, систем унавал хэрэглэгчид мэдэгдэл очно.
- Claude өмнөх яриагаа санахгүй. Шийдвэр, явцыг энэ `docs/` хавтсанд хадгална.
- Сервер, домэйн, GitHub, Cloudflare бүртгэлүүд компанийн нэр дээр байна.
- Хэрэглэгчтэй монгол хэлээр, техникийн үг аль болох цөөн хэрэглэж харилцана.

### Компани

- 50 орчим ажилтан. Хэд хэдэн ХХК-тай.
- ХХК бүрийн мэдээлэл тусдаа хадгалагдана. Нэг ажилтан хэд хэдэн ХХК-д харьяалагдаж болно.
- Ажилтан бүр өөрийн бүртгэлээр нэвтэрнэ. Ерөнхий захирал (супер админ) бүх эрхтэй.
- Удирдлага, хэлтсийн бүтцийг [org-structure.md](org-structure.md)-д хөтөлнө.
- Дизайн маш чухал. Хэрэглэгч үүнийг онцолж хэлсэн.
- Систем дээр гүйлгээ хийхгүй: нягтлан бодох бүртгэл, И-баримт, банкны интеграц хэрэггүй.
  **Тодруулах:** хэрэглэгч "Гүйлгээ нрт хийхгүй ээ" гэж бичсэн. Энэ утгаар ойлгосон боловч хараахан баталгаажуулаагүй.

### Сервер

- **Туршилтын үе:** Cloudflare (Workers болон static assets). Өгөгдлийн сан нь PostgreSQL, Neon гэх мэт үнэгүй үйлчилгээ ашиглана.
- **Бодит ашиглалт:** Монголын дата төвийн VPS дээр Docker-оор ажиллуулна. Эсвэл хуулийн зөвлөгөө авсны дараа Cloudflare дээр үлдэж болно.
- Нэг код Cloudflare дээр ч, энгийн Node.js/Docker сервер дээр ч өөрчлөлтгүй ажиллах ёстой.
- Туршилтын үед ажилчдын РД, цалин зэрэг жинхэнэ хувийн мэдээлэл оруулахгүй, жишээ өгөгдлөөр туршина.
  Учир нь Хувийн мэдээлэл хамгаалах тухай хуулиар хувийн мэдээллийг гадаадад шилжүүлэхэд тухайн хүний зөвшөөрөл эсвэл хуулийн үндэслэл шаардлагатай.

### Технологи

- Хэл: TypeScript (backend, frontend хоёуланд).
- Архитектур: modular monolith. Нэг програм, дотроо модулиудад хуваагдсан, нэг өгөгдлийн сантай.
- Backend: Hono. Cloudflare Workers болон Node.js аль алин дээр ажилладаг. Cloudflare дээр тохиромжгүй тул NestJS-ийг сонгоогүй.
- Өгөгдлийн сан: PostgreSQL.
- Frontend: React, Vite, Ant Design (`mn_MN` locale).
- Дараа шийдэх: ORM, нэвтрэх систем (auth), файл хадгалах арга.

### Дизайн

- Фонт сонгохдоо монгол Ө, Ү үсэг байгаа эсэхийг заавал шалгана. Үгүй бол тэдгээр үсэг өөр фонтоор харагдаж эвдэрнэ.
  - Шалгасан, ашиглаж болно: Golos Text, IBM Plex Mono, Literata, Manrope, Montserrat, Onest, PT Serif, Prata, Raleway, Rubik, Commissioner, Exo 2.
  - Ө, Ү байхгүй: Unbounded, Wix Madefor Display.

### Гадны хэрэгслүүд

- **Agent Reach** (Panniantong/Agent-Reach): туршсан, ашиглахгүй. Энэ cloud орчинд сүлжээний хязгаарлалтаас болж ажилладаггүй.
  Instagram, X зэрэг сайтыг уншихдаа хэрэглэгчийн бүртгэлийг илрүүлэлтээс нуугддаг хөтчөөр ашигладаг тул бүртгэл хаагдах эрсдэлтэй.
- **Dimensional Drawing** (enesozturk/dimensional-drawing, MIT): UI элементийн зай, радиус, давхаргыг Apple-ийн техникийн зураг маягаар нэг хуудсанд зурдаг Claude skill.
  Хэрэглэгч Claude-ийг дизайны хэрэгслээр тоноглохыг хүссэн тул `.claude/skills/`-д нэмсэн.

## 2026-10-28 (үргэлжлэл): дизайны хэрэгслүүд

- Хэрэглэгчийн өгсөн 12 UI/UX эх сурвалжийг (NN/g, Apple HIG, W3C WAI, GOV.UK, IBM Carbon, Shopify Polaris) судалж, `.claude/skills/erp-ui-guidelines` болгон нэгтгэсэн. ERP-ийн бүх дэлгэцийг энэ дүрмээр зохионо.

- **Ant Design-ийн хувилбар:** v6 (2026-10-28-нд 6.6.8). Анхдагч өнгөнүүдийн хэд хэдэн нь WCAG-ийн тодролын шаардлагыг хангадаггүй тул theme дээр засна (`erp-ui-guidelines/references/antd.md`).

  - Эдгээр болон тэдний холбогдох skill-үүдийг (бүгд MIT) `.claude/skills/`-д нэмсэн. Жагсаалт ба сонгосон шалтгаан нь `.claude/skills/README.md`-д бий.

## 2026-10-28 (үргэлжлэл): ажилтны хэрэгслүүд

**Ажлын дараалал.** Эхлээд дизайныг батлуулна. Дараа нь ажилтны хэрэгслүүдийг хийнэ.

**Ерөнхий санаа.** Ажилтан системийг өдөр бүр ашиглах жижиг хэрэгслүүдээр хангана. Хэрэглэгч одоогоор хоёр санаа гаргасан: PDF засах хэрэгсэл, ажлын тэмдэглэл.

### PDF хэрэгсэл: тохиролцсон төлөвлөгөө

1. **Энгийн хэрэгслүүд** (нэгтгэх, салгах, хуудас эрэмбэлэх, гарын үсэг, усан тэмдэг, хуудасны дугаар гэх мэт). Ажилтны хөтөч дотор ажиллана, файл гадагш гарахгүй, сервер хэрэггүй.
   - Stirling-PDF-ийн үнэгүй (MIT) кодоос хуулж авна. Зохиогчийг дурдана.
   - Дэлгэцийг Ant Design болон манай дүрмээр дахин хийнэ.
   - Хэрэглэгч эхний 3–5 хэрэгслийг хараахан сонгоогүй.
2. **AI-тай хэрэгслүүд** (монгол текст таних, товчлох, мэдээлэл гаргах, орчуулах). OpenRouter-оор хямд загвар ашиглана.
   - Хэд хэдэн загварыг монгол баримт дээр туршиж сонгоно.
   - Ажилчдын хувийн мэдээлэл, нууц гэрээг илгээхгүй, эсвэл мэдээлэл хадгалдаггүй үйлчилгээ үзүүлэгчийг л сонгоно.
   - AI-ийн үр дүнг ажилтан шалгадаг байна.
   - Сарын зардалд дээд хязгаар тавина. API түлхүүрийг серверт хадгална.
3. **Сервер шаардлагатай хэрэгслүүд** (Word/Excel ↔ PDF, файл багасгах). Өөрийн сервертэй болсон үед хийнэ. Stirling-PDF-ийн үнэгүй хувилбарыг серверт ажиллуулж болно.

### Судалсан эх сурвалж

- **sammyZi/pdf-tools.** Android апп, MIT. 24 хэрэгсэл болон баримт скан хийгчтэй, бүгд утсан дээр ажилладаг. Шууд ашиглах боломжгүй, зөвхөн жишээ болгоно.
- **Stirling-Tools/Stirling-PDF.** 2026-10-28-нд commit `78bea24`-ийг судалсан.
  - **Лиценз:** open-core.
    - MIT: `app/core` болон `frontend/src/editor/core` зэрэг үндсэн хэсэг.
    - Төлбөртэй: `app/proprietary`, `app/saas`, `engine`, `frontend/src/editor/{proprietary,desktop,saas,cloud}`, `frontend/src/processor` хавтсууд. Төлбөргүйгээр зөвхөн туршиж болох ба хуулахыг хориглосон.
    - Төлбөртэй хэсэгт хэрэглэгчийн нэвтрэлт ба SSO, аудит, AI, ажлын урсгал, хадгалалт ордог.
  - **Үнэгүй хувилбар:** зөвхөн үнэгүй хэсгийг `STIRLING_FLAVOR=core` эсвэл `DISABLE_ADDITIONAL_FEATURES=true`-ээр бүтээнэ. Бэлэн Docker багцад төлбөртэй хэсэг нь орсон байдаг.
  - **Ажиллах орчин:**
    - Сервер тал нь Java болон LibreOffice, Tesseract зэрэг програмууд дээр ажилладаг, Cloudflare дээр ажиллахгүй.
    - 40 гаруй хэлтэй ч монгол хэл байхгүй.
  - **Вэб хэсэг:** React 19 болон Mantine дээр бичигдсэн. Хөтөч дотор PDF боловсруулахдаа дараах сангуудыг ашигладаг:
    - EmbedPDF (`@embedpdf/*`, MIT, PDFium)
    - `@cantoo/pdf-lib` (MIT, нууц үг тавих боломжтой)
    - `pdfjs-dist` (Apache-2.0)
  - **Бусад:** монгол текст танихад `tesseract.js` (Apache-2.0)-ийг AI-тай харьцуулж туршиж болно.

### Ажлын тэмдэглэл

- хурлын тэмдэглэл (шийдвэр, даалгавартай)
