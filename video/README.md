# ERP танилцуулга бичлэг

Ажилчдад зориулсан 58 секундын босоо бичлэг (1080×1920). Арга нь `.claude/skills/cinematic-video/SKILL.md`-д бий: three.js тайзыг Playwright-аар кадр бүрээр зурж, ffmpeg-ээр MP4 болгоно, дууг numpy-оор хийнэ.

| Файл | Юу хийдэг |
|---|---|
| `erp-intro/timeline.js` | Хэсгүүдийн дараалал, урт, тайлбар бичиг, логоны үсрэлт, утасны дэлгэц дээрх товшилт |
| `erp-intro/scene.js` | 3D тайз: лого, утас, гэрэл, камер, эффектүүд. `seek(t)` нь `t` секундын кадрыг зурна |
| `capture.mjs` | Туршилтын хаягаас апп-ын дэлгэцийг утасны хэмжээгээр (390×844, 3x) авч `shots/`-д хадгална. Талбар, товч, доод цэсний байрлалыг `shots/geometry.json`-д бичнэ. Туршилтын «Жишээ эрхүүд» хэсгийг нууна |
| `render.mjs` | Кадрыг `frames/`-д зурна |
| `sfx.py` | Дуу: хөдөлгөөний агшин бүрт эффект, арын аккорд |
| `build.py` | Дэд кадруудыг дундажилж (motion blur), дуутай нь MP4 болгоно |
| `logo/` | Логоны вектор хувилбар (`logo.svg`) ба 3D-д хэрэглэдэг цэгүүд (`logo.json`) |

## Дахин гаргах

```bash
cd video && npm install
node capture.mjs                      # дэлгэцийн зургууд repo-д ороогүй тул эхлээд авна
node render.mjs --preview             # 540×960, 30 fps, ~12 минут: агуулгыг шалгах
python3 sfx.py && python3 build.py out/erp-intro-preview.mp4
node render.mjs                       # 1080×1920, 60 fps, motion blur: 1.5 цаг орчим
python3 sfx.py && python3 build.py out/erp-intro.mp4
```

- Энэ container-т видео карт байхгүй тул Chromium зургийг процессороор зурдаг (SwiftShader). Гүний бүдгэрэлт (DOF) хамгийн удаан алхам нь (1.85 секундээс 1.15 секунд) учраас утасны хэсэгт түүнийг унтраадаг. Оронд нь ар талын гурвалжингуудыг урьдчилан бүдгэрүүлсэн зургаар харуулна.
- Утасны дэлгэцийг тусад нь, tone mapping-гүй зурдаг. Ингэснээр апп-ын өнгө яг хэвээрээ харагдана. Ингэхдээ `scene.background`-ыг түр `null` болгох хэрэгтэй, эс бөгөөс three.js бүх кадрыг цэвэрлэчихнэ.
- Тайлбар бичгийг Gemini-ээр хянуулсан (`docs/decisions.md`). Өөрчлөх бол дахин хянуулна.
- Хаяг өөрчлөгдвөл `timeline.js`-ийн `ADDRESS`-ийг солино.

# Кемпэд гал гарвал (ХАБЭА бичлэг)

Ажилчдад зориулсан 49 секундын босоо бичлэг (1080×1920, 30 fps). Кемпийн аврах гарцын схемийг 3D загвар болгосон: схем шалан дээр хэвлэгдсэн, өрөө бүр нам ханатай. Гал, утаа, дохиолол, хүмүүсийн гарах замыг хоолойтой зэрэг харуулна. Камер өгүүлбэр бүрт шинэ байрлалаас хөдөлнө. Өмнөх 2D хувилбар git-ийн түүхэнд бий (commit `54b26cd`).

- **Хана:** схемийн өрөөнүүдээс автоматаар босгодог. Хүний явах зам ханыг огтолсон газар хаалга гарна.
- **Хүмүүс:** 17-р өрөөний ажилтан дохиоллын товчийг дарна. 18-р өрөөний ажилтан утаатай коридороор бөхийж гарна, камер түүнийг дагана. Бусад нь ногоон сумаар гарч, аюулгүй талбайд цуглана.

| Файл | Юу хийдэг |
|---|---|
| `hse-fire/voice.mp3`, `voice.json` | Хэрэглэгчийн ElevenLabs-аар уншуулсан хоолой, үг тус бүрийн цагтай бичвэр |
| `hse-fire/plan-video.svg`, `plan-geom.json` | Схем ба түүний цэгүүд. `docs/hse/evacuation/plan.py` бичдэг, гараар засахгүй |
| `hse-fire/captions.json` | Дэлгэц дээрх богино бичиг (Gemini) |
| `hse-fire/scene.js` | three.js тайз ба `seek(t)`: камер, гал, утаа, хүмүүс, бичиг. Бүх хэсэг `voice.json`-ийн өгүүлбэр, үгийн цагаас хамаарна |
| `hse-fire/audio.py` | Хоолой, намуухан хөгжим, галын чимээ, дохиоллын дуу |

```bash
cd video
node render.mjs --scene=hse-fire --stills 4,10.8,18,30   # шалгах зургууд out/-д
for k in 0 1 2; do node render.mjs --scene=hse-fire --part=$k/3 & done; wait   # 1468 кадр × 2 дэд кадр, ~1 цаг
python3 hse-fire/audio.py && python3 build.py out/hse-fire.mp4 out/hse-fire-audio.wav
```

- Шинэ хоолой ирвэл `voice.mp3`, `voice.json`-ийг солиод дахин ажиллуулна. Бичлэг өөрөө шинэ цагт тааруулагдана. Хоолой 7 өгүүлбэртэй байх ёстой.
- Схем өөрчлөгдвөл `python3 docs/hse/evacuation/plan.py`-г дахин ажиллуулна.
