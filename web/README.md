# ERP: вэб програм

Pane загварыг дагаж хийсэн ERP-ийн дэлгэцүүд, ард нь сервер (`server/`).

- **Сервертэй үед** (амьд хаяг, эсвэл `ERP_DB`-тэй `server/main.ts`): өгөгдөл сервер дээрх санд хадгалагдана. Хүмүүс нэвтэрч, нэг өгөгдөл дээр ажиллана. Хэн юу харж, өөрчилж болохыг сервер шалгана. Хөтөч зөвхөн нээлттэй ХХК, харагдах байдлыг хадгална (`erp:prefs`).
- **Сервергүй үед** (туршилтын хуудас, сервергүй preview): өгөгдөл хөтчийн localStorage-д `erp:data` нэрээр хадгалагдана: хөтөч бүрт тусдаа, нэвтрэлт ба эрхийг ч хөтөч шалгана.

Систем хоосон эхэлнэ: анхны хуудас «Системийг эхлүүлэх» нь эхний ХХК, ганц админыг үүсгэнэ (сервертэй үед ирцийн кодоор хамгаалагдана). Жишээ өгөгдөл (`src/lib/seed.ts`) зөвхөн шалгалтад хэрэглэгдэнэ: хөтөч localStorage-ийн `erp:demo`-д `1` хадгалсан үед л гарч, `erp:v1` нэрээр тусдаа хадгалагдана (`src/lib/demo.ts`), сервер рүү хэзээ ч хандахгүй.

## Ажиллуулах

```bash
cd web
npm ci
npm run dev
```

- `npm run check`: кодын алдааг шалгана.
- `npm run build`: `dist/` хавтсанд багцална.
- `node scripts/clean-flow.cjs`: хоосон системийг шалгана (`npx vite preview --port 4173 --strictPort` ажиллаж байх ёстой).
- `node scripts/tour-walk.cjs` (жишээ өгөгдөл), `node scripts/tour-walk.cjs --empty` (хоосон систем): ERP-ийн заавруудыг алхам бүрээр нь явна.
- `ERP_DB=erp.sqlite node server/main.ts`: серверийг өөрийн компьютер дээр асаана (Node 22.5+, суулгах зүйлгүй). `npm run dev` ба preview `/api`-г түүн рүү дамжуулна.
- `node scripts/server-test.ts`: серверийг хөтөчгүйгээр шалгана (эрх, нэвтрэлт, өгөгдөл солилцох).
- `node scripts/server-flow.cjs`: сервертэй аппыг хөтчөөр шалгана; сервер, preview-г өөрөө асаана (эхлээд `npm run build`).

## Бүтэц

- `src/lib/`: өгөгдөл ба логик.
  - `types.ts`: өгөгдлийн бүтэц.
  - `store.ts`: хадгалах, өөрчлөх үйлдлүүд.
  - `sync.ts`, `merge.ts`, `patch.ts`, `tables.ts`: сервертэй өгөгдөл солилцох (нэвтрэх, илгээх, татах, нэгтгэх).
  - `seed.ts`: хоосон эхлэл (`blank`) ба шалгалтын жишээ өгөгдөл (`seed`).
  - `demo.ts`: жишээ өгөгдлийн унтраалга.
  - `format.ts`: огноо, тоог монголоор бичих.
  - `motion.ts`: GSAP хөдөлгөөн.
  - `router.ts`: хуудасны хаяг.
  - `theme.ts`: горим ба өнгө.
- `server/`: сервер. `api.ts` (хаягууд, нэвтрэлт), `data.ts` (өгөгдөл солилцох), `rules.ts` (хэн юу харж, өөрчилж болох), `db.ts` ба `sqlite.ts` (өгөгдлийн сан), `scan.ts` (скан унших), `timely.ts` (ирц). Cloudflare дээр `worker/site.js`, өөрийн сервер дээр `main.ts` ажиллуулна.
- `src/shell/`: бүх дэлгэцэд байдаг хэсгүүд. Хажуугийн цэс, дээд мөр, хайлт, island, утасны цэс, гарын товчлол.
- `src/screens/`: 7 дэлгэц.
- `src/dialogs/`: цонх ба хажуугийн самбарууд.
- `src/ui/`: дахин ашиглагддаг хэсгүүд. Гарчиг, цэс, сонголтын товч, график.
- `src/styles/`: `tokens.css` (өнгө, хэмжээ), `base.css`, `shell.css`, `charts.css`, `screens/`.

## Дүрэм

- Pane-ийн кодыг хуулахгүй. Demo-г харж хийнэ.
- Шинэ сан нэмэхээсээ өмнө лиценз, суулгах script, сүлжээний хандалтыг шалгаж, үр дүнг `docs/decisions.md`-д бичнэ.
- Сангийн хувилбарыг яг тогтооно. Суулгахдаа script ажиллуулахгүй (`.npmrc`).
