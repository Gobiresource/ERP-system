# ERP: вэб програм

Pane загварыг дагаж хийсэн ERP-ийн дэлгэцүүд. Одоогоор зөвхөн хөтөч дээр ажилладаг. Сервер, нэвтрэх хэсэг хараахан байхгүй. Өгөгдөл хөтчийн localStorage-д `erp:v1` нэрээр хадгалагдана.

## Ажиллуулах

```bash
cd web
npm ci
npm run dev
```

- `npm run check`: кодын алдааг шалгана.
- `npm run build`: `dist/` хавтсанд багцална.

## Бүтэц

- `src/lib/`: өгөгдөл ба логик.
  - `types.ts`: өгөгдлийн бүтэц.
  - `store.ts`: хадгалах, өөрчлөх үйлдлүүд.
  - `seed.ts`: жишээ өгөгдөл.
  - `format.ts`: огноо, тоог монголоор бичих.
  - `motion.ts`: GSAP хөдөлгөөн.
  - `router.ts`: хуудасны хаяг.
  - `theme.ts`: горим ба өнгө.
- `src/shell/`: бүх дэлгэцэд байдаг хэсгүүд. Хажуугийн цэс, дээд мөр, хайлт, island, утасны цэс, гарын товчлол.
- `src/screens/`: 7 дэлгэц.
- `src/dialogs/`: цонх ба хажуугийн самбарууд.
- `src/ui/`: дахин ашиглагддаг хэсгүүд. Гарчиг, цэс, сонголтын товч, график.
- `src/styles/`: `tokens.css` (өнгө, хэмжээ), `base.css`, `shell.css`, `charts.css`, `screens/`.

## Дүрэм

- Pane-ийн кодыг хуулахгүй. Demo-г харж хийнэ.
- Шинэ сан нэмэхээсээ өмнө лиценз, суулгах script, сүлжээний хандалтыг шалгаж, үр дүнг `docs/decisions.md`-д бичнэ.
- Сангийн хувилбарыг яг тогтооно. Суулгахдаа script ажиллуулахгүй (`.npmrc`).
