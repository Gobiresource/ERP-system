# ERP: вэб програм

Pane загварыг дагаж хийсэн ERP-ийн дэлгэцүүд. Өгөгдөл одоогоор хөтчийн localStorage-д `erp:data` нэрээр хадгалагдана: хөтөч бүрт тусдаа, нэвтрэлт ба эрхийг ч хөтөч шалгадаг. Сервер нь скан унших (`/api/scan`) ба ирц (`/api/attendance`) хоёрыг л хариуцна.

Систем хоосон эхэлнэ: анхны хуудас «Системийг эхлүүлэх» нь эхний ХХК, ганц админыг үүсгэнэ. Жишээ өгөгдөл (`src/lib/seed.ts`) зөвхөн шалгалтад хэрэглэгдэнэ: хөтөч localStorage-ийн `erp:demo`-д `1` хадгалсан үед л гарч, `erp:v1` нэрээр тусдаа хадгалагдана (`src/lib/demo.ts`).

## Ажиллуулах

```bash
cd web
npm ci
npm run dev
```

- `npm run check`: кодын алдааг шалгана.
- `npm run build`: `dist/` хавтсанд багцална.
- `node scripts/clean-flow.cjs`: хоосон системийг шалгана (`npx vite preview --port 4173 --strictPort` ажиллаж байх ёстой).
- `node scripts/tour-walk.cjs` (жишээ өгөгдөл), `node scripts/tour-walk.cjs --empty` (хоосон систем): ERP-ийн заавруудыг алхам бүрээр нь явна.

## Бүтэц

- `src/lib/`: өгөгдөл ба логик.
  - `types.ts`: өгөгдлийн бүтэц.
  - `store.ts`: хадгалах, өөрчлөх үйлдлүүд.
  - `seed.ts`: хоосон эхлэл (`blank`) ба шалгалтын жишээ өгөгдөл (`seed`).
  - `demo.ts`: жишээ өгөгдлийн унтраалга.
  - `format.ts`: огноо, тоог монголоор бичих.
  - `motion.ts`: GSAP хөдөлгөөн.
  - `router.ts`: хуудасны хаяг.
  - `theme.ts`: горим ба өнгө.
- `src/shell/`: бүх дэлгэцэд байдаг хэсгүүд. Хажуугийн цэс, дээд мөр, хайлт, island, утасны цэс, гарын товчлол.
- `src/screens/`: 7 дэлгэц.
- `src/dialogs/`: цонх ба хажуугийн самбарууд.
- `src/ui/`: дахин ашиглагддаг хэсгүүд. Гарчиг, цэс, сонголтын товч, график.
- `src/styles/`: `tokens.css` (өнгө, хэмжээ), `base.css`, `shell.css`, `charts.css`, `screens/`.

## Дүрэм

- Pane-ийн кодыг хуулахгүй. Demo-г харж хийнэ.
- Шинэ сан нэмэхээсээ өмнө лиценз, суулгах script, сүлжээний хандалтыг шалгаж, үр дүнг `docs/decisions.md`-д бичнэ.
- Сангийн хувилбарыг яг тогтооно. Суулгахдаа script ажиллуулахгүй (`.npmrc`).
